# 🎮 坦克大战 (Tank Battle)

经典坦克大战游戏的 HTML5 网页版！无需安装，打开浏览器即可游玩。

## 在线试玩

直接打开 `index.html` 或在浏览器中访问 GitHub Pages 链接即可开始游戏。

## 游戏操作

| 按键 | 功能 |
|------|------|
| ⬆ ⬇ ⬅ ➡ / WASD | 移动坦克 |
| 空格键 | 射击 |
| R | 游戏结束后重新开始 |

## 游戏特色

- 🎯 **波次系统** — 每波敌人越来越多，越来越强
- 🧱 **可破坏的砖墙** — 子弹可以击碎砖墙开辟通道
- ⛓️ **坚不可摧的钢墙** — 需要绕道而行
- 💧 **水域障碍** — 坦克无法通过
- 🦅 **保护基地** — 守护你的基地不被敌人摧毁
- 💥 **爆炸特效** — 炫酷的粒子效果
- 🤖 **智能 AI** — 敌人会追踪你的位置

## 运行方式

### 方式一：直接打开
双击 `index.html` 在浏览器中打开即可。

### 方式二：本地服务器
```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js
npx serve .
```

然后在浏览器中访问 `http://localhost:8080`。
